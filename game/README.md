# Code du jeu

- `cards.gd` : catalogue, validation et accès aux données `data/cards.json`.
- `calendar.gd` : calendrier, collection, liens et progression.
- `combat/` : moteur commun, personnages, équipes, decks et effets génériques.
- `battle.gd`, `team_battle.gd` : adaptateurs des écrans de combat.
- `campaign/` : session et sauvegardes versionnées.
- `presentation/` : dialogues, localisation, commandes et son.

`visual/` contient les scènes et leurs contrôleurs. `prototypes/` est réservé aux outils laboratoire et simulations.
